Private backup

Download a raw slot for recovery. The downloaded file contains private device identity and Wi-Fi credentials.

Validated restore

The file must be exactly 0x80000 bytes and match this router's Factory MACs, country VN, KN-3811 identity, checksums and recovery defaults.

WARNINGS
  • Provision and restore may erase/write both U-Config regions. Do not power off.
  • Restore commits the recovery slot first, verifies it, then commits the active slot.
  • Backups are device-specific and must not be shared between routers.
  • This page does not edit U-Boot environment variables.
